Sacarle partido a la IA

Configurar tu asistente una vez, resumir vídeos y documentos, investigar con fuentes y elegir qué IA usar para cada cosa.

search

No hay ningún prompt para eso todavía. Prueba con otra palabra o cuéntanos qué necesitas.

01

Configurar tu IA una vez para no repetirle quién eres

Cada vez que abres un chat le explicas lo mismo: tu trabajo, cómo quieres las respuestas...

Prompt · rellena lo resaltado
Ayúdame a escribir mis instrucciones personalizadas para [ChatGPT / Claude / Gemini].
Sobre mí: [trabajo, ciudad, para qué uso la IA, nivel técnico].
Cómo quiero las respuestas: [cortas / con pasos / sin rodeos / en tablas / tuteándome].
Lo que no soporto: [respuestas largas, frases de relleno, que me dé la razón en todo...].

Escríbeme dos bloques listos para pegar, "Qué debe saber de mí" y "Cómo quiero que responda", de menos de 1.000 caracteres cada uno. Luego dime dónde se pegan en la herramienta que uso.
02

Saber qué IA usar para lo que necesitas

No sabes si usar ChatGPT, Claude, Gemini, Copilot o Perplexity para una tarea.

Prompt · rellena lo resaltado
Quiero hacer esto: [resumir PDFs / buscar información actual / escribir / programar / crear imágenes / hablar por voz...].
Tengo [cuentas gratuitas / pago de X]. Uso sobre todo [móvil / ordenador] y [Google / Microsoft / Apple].

1. Dime qué tipo de herramienta encaja mejor y por qué.
2. Dime qué puede hacer la versión gratuita y qué no.
3. Escríbeme el primer prompt que debería usar para esta tarea.
Si no tienes información actualizada de funciones o precios, dilo.
03

Resumir un vídeo largo o un podcast

Tienes un vídeo de YouTube o un audio de una hora y quieres saber si merece la pena.

Prompt · rellena lo resaltado
Te paso la transcripción de [un vídeo / un podcast / una clase] de [duración] sobre [tema].

1. Resumen en 5 frases.
2. Las ideas principales, con el minuto aproximado si aparece en la transcripción.
3. Qué es opinión y qué es dato.
4. ¿Merece la pena verlo entero para alguien que quiere [tu objetivo]? Dime qué partes.

Transcripción:
[pégala aquí; en YouTube suele estar en «Más» > «Mostrar transcripción»]
04

Investigar un tema con fuentes que puedas comprobar

Necesitas información fiable y actual, no lo que la IA «cree recordar».

Prompt · rellena lo resaltado
Investiga [tema o pregunta] porque [para qué lo necesito].
Usa la búsqueda en internet si la tienes; si no puedes buscar, dímelo al principio.

1. Responde en 5-8 puntos claros.
2. Pon la fuente de cada dato (medio o web y fecha).
3. Separa lo que está bien establecido de lo que se discute o es opinión.
4. Dime qué fuentes oficiales o expertas debería consultar para confirmarlo.
No inventes enlaces ni cifras: si no encuentras algo, dilo.
05

Hacerle preguntas a un PDF o un documento largo

Tienes un manual, unas bases, un contrato o un informe y quieres encontrar respuestas rápido.

Prompt · rellena lo resaltado
Te adjunto [tipo de documento]. Responde solo con lo que dice este documento.

Para cada pregunta que te haga:
- Responde en 2-3 frases.
- Cita el fragmento exacto y di en qué página o apartado está.
- Si el documento no lo dice, responde "No aparece en el documento".

Primera pregunta: [tu pregunta]
06

Convertir una petición vaga en un buen prompt

La IA te da respuestas genéricas y no sabes cómo pedírselo mejor.

Prompt · rellena lo resaltado
Quiero pedirte esto: [lo que quieres, tal como te sale].

Antes de responder, hazme hasta 5 preguntas para entender el contexto, el objetivo, para quién es y en qué formato lo quiero. Con mis respuestas, escribe tú el prompt ideal para esta tarea, enséñamelo y luego ejecútalo.
07

Comprobar si la IA se ha inventado algo

Te ha dado datos, cifras o citas y no sabes si fiarte.

Prompt · rellena lo resaltado
Revisa tu respuesta anterior como si fueras un verificador exigente:

1. Haz una lista de cada dato, cifra, fecha, nombre o cita que has dado.
2. Marca cada uno como: seguro / probable / no lo sé con certeza.
3. Para los que no son seguros, dime cómo y dónde comprobarlos.
4. Corrige lo que creas que está mal.
08

Crear tu propio asistente para una tarea que repites

Siempre le pides lo mismo a la IA (contestar clientes, corregir textos, preparar clases) y quieres un asistente fijo.

Prompt · rellena lo resaltado
Quiero crear un asistente personalizado (un GPT, un Gem o un Proyecto) para [tarea que repito].
Cómo lo hago ahora: [pasos]. Lo que le pasaría: [...]. Lo que debería devolverme: [formato exacto].

Escríbeme:
1. Las instrucciones completas del asistente, listas para pegar.
2. Qué documentos de referencia debería subirle.
3. 3 ejemplos de uso para probarlo.
09

Ensayar una conversación con el modo voz

Quieres practicar una entrevista, una llamada difícil o un idioma hablando.

Prompt · rellena lo resaltado
(Usa el modo voz de la app.) Vamos a ensayar [una entrevista de trabajo / una llamada para reclamar / una conversación en inglés / otro].
Tú haces de [quién] y yo de mí. Situación: [contexto].
Habla con frases cortas y naturales, como una persona real. Cuando diga "pausa", dime qué he hecho bien y qué mejorar, y seguimos.
10

Crear una instrucción reutilizable para Gemini, ChatGPT o Claude

Repites siempre las mismas indicaciones y quieres guardarlas como skill, GPT, proyecto o instrucción personalizada.

Prompt · rellena lo resaltado
Cada semana le pido a la IA esta tarea: [describe la tarea y un ejemplo de lo que sueles escribir].

Conviértela en una instrucción reutilizable que pueda guardar como skill de Gemini, GPT personalizado, proyecto de Claude o instrucción personalizada. Incluye:
- Rol y objetivo.
- Qué datos le daré cada vez.
- Formato exacto de la respuesta.
- Reglas: tono, longitud, qué evitar.
- Qué preguntar si falta información.

Que sea breve (menos de 200 palabras) y escrita para que funcione en cualquier asistente.
Segundo mensaje

Pruébala con este caso real y dime qué ajustarías: [caso].

11

Usar una IA en tu ordenador sin enviar tus datos

Quieres trabajar con documentos privados y prefieres que nada salga de tu ordenador.

Prompt · rellena lo resaltado
Quiero usar una IA en local, sin internet. Mi ordenador: [Windows / Mac / Linux], [cantidad] de memoria RAM, [tarjeta gráfica si la sé].
Para qué la quiero: [resumir documentos privados / escribir / programar / otro].

1. Dime si mi ordenador es suficiente y qué tamaño de modelo puedo usar.
2. Explícame paso a paso cómo instalar una herramienta gratuita para ejecutar modelos en local.
3. Recomiéndame 2 modelos abiertos para mi uso y por qué.
4. Explícame cómo hacer preguntas a mis PDFs sin subirlos a ningún sitio.
5. Dime con sinceridad en qué será peor que un asistente en la nube.

Cómo usarlos
  • Pulsa Copiar, pégalo en ChatGPT, Claude, Gemini o Copilot y cambia lo que va entre [corchetes] por tus datos.
  • Cuanto más concreto seas en los corchetes, mejor será la respuesta.
  • Si la respuesta se queda corta, contesta «más concreto» o «dame 3 alternativas».
  • Nunca pegues contraseñas, DNI, números de cuenta ni datos de otras personas.

Ojo: Funcionan en ChatGPT, Claude, Gemini, Copilot y similares. Los menús de cada app cambian a menudo: si una opción no está donde dice la IA, búscala en su ayuda oficial.
